# Security Policy

## Reporting a vulnerability

If you discover a security issue in BlowingBubbles, please report it privately
instead of opening a public issue:

- Email: **oliver@mohr.dk** (the maintainer listed in `pyproject.toml` / `CITATION.cff`)

Please include a description of the issue, steps to reproduce, and the affected
version. You can expect an acknowledgment within a few days.

## Supported versions

Security fixes are applied to the latest release only. Please keep your
installation up to date (`uv sync` / `pip install -U blowing-bubbles`).
