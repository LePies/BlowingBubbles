Academic citation
-----------------

Citation is requested **only for published scientific work** (journal or conference
articles, public theses, preprints, citable technical reports). It is **not**
required for private study, internal prototyping, or unpublished exploratory use.
Details are in :file:`ACADEMIC_CITATION.md`.

Copy the BibTeX entry below into your bibliography, or use :file:`CITATION.cff` with
tools that support `Citation File Format <https://citation-file-format.github.io/>`_.
Update the ``TODO`` fields when the accompanying paper is published. The canonical
BibTeX file is :file:`../CITATION.bib`.

.. code-block:: bibtex

   @article{mohr_blowingbubbles2026,
     author  = {Mohr, Oliver and {TODO: co-authors}},
     title   = {{TODO: Paper title for BlowingBubbles}},
     journal = {{TODO: Journal or conference}},
     year    = {2026},
     volume  = {},
     number  = {},
     pages   = {},
     doi     = {{TODO: DOI when available}},
     note    = {Software: BlowingBubbles. Manuscript in preparation; update this entry when published.}
   }
